# Licensing Decision Required for Public Release

The academy is already viewable on GitHub, but no open-source license has been chosen by the maintainer. Public visibility does not automatically permit redistribution.

## Recommended options — approval required

- Original platform code, grader scripts and workflows: MIT license.
- Original educational briefs, diagrams and written explanations: Creative Commons Attribution 4.0 International.
- Synthetic training fixtures: explicitly include in the approved code/content license scope.
- Third-party resources: link to Apache, Python and cloud documentation and respect upstream licenses; do not copy textbooks into this repository.
- Contributor changes: compatible with approved project license.

**No actual license text should be committed before the owner approves these terms.** Adding licenses publicly is a meaningful legal permission decision, and it is a public launch blocker.
